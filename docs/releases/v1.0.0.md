# Mimus v1.0.0 — draft release notes

Prepared for review; not published. The release date and target commit are not
selected until the [release checklist](../release-checklist.md) is resolved.

Mimus is a small personal project that rewrites English between Human, LinkedIn,
Corporate, Startup Founder, and Academic registers, with three intensity levels.
The repository includes the application, reproducible evaluations, and dated
records of the decisions and limitations.

## Included

- Streamed rewrites with Stop, Regenerate, Swap, Clear, and copy controls.
- Prewritten examples and a useful demo that requires no provider key.
- Responsive keyboard interaction, preferences, and optional bounded history
  stored only in the browser.
- Server-side OpenRouter access to Gemini 3.5 Flash-Lite at minimal reasoning,
  prompt v4, and a 2,048-token cap. Requests require endpoints OpenRouter classifies
  as ZDR and deny data collection; the announced October 18 change still needs review.
- A reproducible offline benchmark covering model and reasoning-effort choices,
  evaluator calibration, limited blind human review, repeatability, and a fresh
  release comparison. The decision-model cascade remains an offline experiment.
- Automated checks, a documented deployment/runbook, and dated operational
  evidence, including cancellation reaching the function and disabled-mode
  recovery. The [design notes](../case-study.md) explain the decisions and evidence.

## Repository maintenance

The maintenance update repairs first-chunk output-limit enforcement and browser
storage fallback/migration, extracts browser stream handling and history display,
and adds gated mocked-browser streaming and accessibility checks. Formatting is
checked in CI. `npm run eval:verify` checks the published sanitized release
comparison offline, without provider access or changes to historical labels.

The [maintenance verification record](../../evals/results/maintenance-verification-2026-10-16.md)
tracks the current candidate and separates local checks from pending deployment
and privacy-policy verification. These remain draft notes, not a publication.

## Limits to carry into the final notes

Meaning preservation is not guaranteed. Gemini met the frozen automated release
targets on the forty synthetic cases, with limited and uneven human auditing.
Production also produced a percentage-versus-percentage-point error that the
maintainer accepted for now. Keep that finding visible.

Live inference costs money, depends on provider eligibility and account limits,
and is restricted to the approved visitor-region policy. ZDR routing is not
anonymity. Stopping a request does not guarantee that upstream billing stops.
The final notes must retain the evidence gaps and provider/dependency decisions
listed in the release checklist; they must not claim full release readiness
before those decisions are resolved.
